<pre># Calculator CLI App

A simple Command Line Calculator application built using Python.
This project performs basic arithmetic operations such as Addition, Subtraction, Multiplication, and Division through a user-friendly terminal interface.

## Features

* Addition of two numbers
* Subtraction of two numbers
* Multiplication of two numbers
* Division with zero-division handling
* Continuous execution using loops
* Error handling for invalid inputs

## Technologies Used

* Python
* VS Code / Any Text Editor
* Command Line Interface (CLI)

## Concepts Used

* Functions
* Loops
* Conditional Statements
* User Input Handling
* Exception Handling

## How to Run

1. Save the file as `calculator.py`
2. Open terminal in the project folder
3. Run the command:

```bash
python calculator.py
```

## Outcome

This project demonstrates the fundamentals of Python programming and helps beginners understand CLI-based application development.<pre>
